## 遇到的问题和解决 

1. 问题：axios拦截器中Token携带后后端无法识别，请求头格式错误。解决：修正请求头写法为`config.headers['Authorization'] = 'Bearer ' + token`，确保Bearer后有空格，符合JWT规范。 
2.  问题：Mock数据与前端API接口路径不匹配，请求404。解决：按前端API路径配置db.json，将管理员接口放在api/admin下，失物/招领直接根路径，与JSON Server的路由规则匹配。
3. 问题：分页/筛选参数传递时，后端Mock未识别。解决：在前端API封装时将参数放在`params`中，JSON Server自动支持查询参数筛选和分页。
