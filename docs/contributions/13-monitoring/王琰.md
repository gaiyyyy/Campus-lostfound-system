## 遇到的问题和解决

1. 问题：健康检查端点返回 404

   解决：在 nginx.conf 中添加 `/health` location 配置，使用 `return 200 'healthy'` 直接返回

2. 问题：前端日志格式不统一

   解决：封装 logger.js 工具类，统一输出 JSON 格式，便于日志收集和分析

3. 问题：Vue 组件错误无法被 window.onerror 捕获

   解决：在 main.js 中配置 `app.config.errorHandler` 专门处理 Vue 错误

## 心得体会

通过本次监控配置作业，我掌握了前端结构化日志输出、健康检查端点配置和错误捕获的方法。使用 JSON 格式输出日志便于后续接入日志收集系统，在 nginx 中配置 `/health` 端点可以让容器编排工具检测服务状态，而通过 `window.onerror`、`unhandledrejection` 和 `Vue.errorHandler` 的组合可以全面捕获前端运行时错误。这些监控手段不仅提升了系统的可观测性，也能帮助快速定位生产环境问题，让我认识到监控是保障用户体验的重要环节。
