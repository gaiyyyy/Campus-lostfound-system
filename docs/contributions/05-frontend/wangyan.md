## 遇到的问题和解决

1. **问题：** 前端列表筛选时，关键词搜索和分类筛选需要同时生效，且数据来源于后端一次性获取，如何高效实现多条件组合过滤？

   **解决：** 使用 Vue 3 的 `computed` 属性，将原始列表数据作为数据源，根据搜索关键词、分类、状态三个条件进行链式过滤，最后按时间倒序排序返回。这样既保证了过滤的实时性，又避免了对后端的频繁请求。
