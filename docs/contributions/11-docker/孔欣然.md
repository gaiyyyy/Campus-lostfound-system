## 遇到的问题和解决 
1. 问题：后端 Dockerfile 构建时提示找不到 `pom.xml` 和源代码。
   解决：调整了 `Dockerfile` 中的 COPY 路径，从 `backend/pom.xml` 修正为实际嵌套的 `backend/backend/pom.xml`。
2. 问题：本地容器启动时后端服务状态显示 unhealthy。
   解决：发现 `pom.xml` 缺少 `spring-boot-starter-actuator` 依赖，导致健康检查的 `/actuator/health` 端点无法访问。补充依赖后问题解决。
3. 问题：开发环境挂载数据卷覆盖了构建产物导致启动失败。
   解决：在 `compose.yaml` 中移除了 `backend` 服务将本地目录挂载到 `/app` 的错误配置。
4. 问题：本地 Windows 系统因为开启了预览体验计划 (Canary 频道)，导致虚拟化组件 (VirtualMachinePlatform, WSL2) 严重损坏且无法通过 DISM 和图形界面修复，Docker 无法启动。
   解决：为了不阻塞作业进度，将代码 Push 到远程分支，利用 GitHub Codespaces (云端 Linux 环境) 成功拉起所有容器并完成了测试与截图。
