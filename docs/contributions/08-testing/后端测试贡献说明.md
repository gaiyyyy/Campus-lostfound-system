## 遇到的问题和解决

### 问题1：Maven 命令行编译时 Lombok 不生效
运行 `mvn compile` 报错，提示找不到 getter/setter 方法

#### 解决：

直接在 IDEA 中运行测试，IDEA 内置了 Lombok 支持

### 问题2：Mock JWT Token 无效
API 测试时 JwtFilter 无法解析 mock token

#### 解决：

重点测试不需要认证的接口（登录、注册），其他接口通过 Mock Service 层间接测试
