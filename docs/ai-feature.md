# AI 功能集成说明

## 功能概述
- **功能名称**：智能失物匹配助手
- **功能类型**：智能客服/基于上下文的问答
- **使用模型**：DeepSeek Chat API

## 功能描述
用户可以在失物/招领详情页点击"AI匹配"按钮，系统自动调用DeepSeek大模型，分析当前物品与数据库中其他物品的匹配度，智能推荐可能相关的招领/失物信息。

## 技术实现

### 后端
- **接口1**：`POST /ai/match-lost/{id}` - 为失物匹配招领
- **接口2**：`POST /ai/match-found/{id}` - 为招领匹配失主
- **AI调用**：使用RestTemplate调用DeepSeek API
- **安全**：API Key通过环境变量管理

### 前端
- **组件**：`AIMatchButton.vue` - 可复用的AI匹配按钮
- **交互**：点击按钮 → 弹窗显示加载状态 → 展示AI分析结果

## 使用流程
1. 用户进入失物/招领详情页
2. 点击"AI匹配"按钮
3. 系统自动分析并展示匹配结果
